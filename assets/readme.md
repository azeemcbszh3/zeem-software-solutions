# Zeem Software Solutions website

Static brochure site for Zeem Software Solutions.

## Run locally
- Install the “Live Server” extension in VS Code.
- Right-click `index.html` → “Open with Live Server”.
- Navigate between pages via the header.

## Deploy
- GitHub Pages:
  1. Commit and push this folder to a GitHub repository.
  2. Settings → Pages → Deploy from branch → main → root.
- Netlify:
  1. Drag-and-drop the folder into Netlify or connect the repo.
  2. Netlify will auto-deploy static files. Contact form works via Netlify forms.
- Vercel:
  1. Import the repo, framework “Other”.
  2. Deploy with default settings.

## Customization
- Replace images in `assets/` with your own.
- Update copy in `index.html`, `services.html`, `about.html`, and `contact.html`.
- Adjust brand colors in `styles.css` under `:root`.
